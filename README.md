# Animated Login Page

A visually appealing animated login page built with **HTML**, **CSS**, and **JavaScript**.  
The page features a circular login form with glowing rays animation around the center.



## Features

- Circular login form with **Username** and **Password** inputs
- Animated **Login** button with hover effect
- Glowing rays animation around the center
- Fully responsive design
